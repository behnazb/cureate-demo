# Shop Category banner thumbnails

Drop banner thumbnail images here for the Edit Banner picker on the vendor
My Profile page. The picker's Shop Category dropdown lists the PARENT
categories below; each CHILD category renders as one tile in the grid,
loading its image from this folder using the exact paths listed here.

Format: JPG (aim for wide crops, e.g. 1600x400+ — tiles render 76px tall,
and the chosen image becomes the full 230px shop banner). A tile whose
image is missing shows a neutral placeholder, so you can upload in batches.
